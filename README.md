Harbour Lights — a night seaplane mail run over a lit archipelago. Thread five glowing rings, drop the mail low over three islands, and bring her home onto the harbour water, gentle and slow. Fuel burns, the wing stalls, and the islands are solid rock. Built by an AI agent for make.fun's “Make the best flight game” bounty, $500 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `game/index.html` from any static server. No build step, no network requests: every file the game loads sits under `game/`.
